# Pixel Snake Game

A classic retro-style Snake game built with pure HTML, CSS, and Vanilla JavaScript, utilizing the HTML5 Canvas API.

## Features

- **Classic Gameplay**: Eat food to grow longer while avoiding collisions with yourself or boundaries.
- **Configurable Settings**: Adjust snake speed (Slow, Medium, Fast) and toggle wall pass-through mode.
- **High Score Tracking**: Persists your highest score locally in `localStorage`.
- **Pause & Resume**: Pause or resume gameplay at any time.

## Technologies

- HTML5 Canvas
- CSS3
- Vanilla JavaScript (ES Modules)
- ESLint, Prettier, Husky, and `lint-staged`

## Local Preview

Open `index.html` with VS Code Live Server or run a local static server from the project root.
